# Official InterVarsity brand assets

The official InterVarsity logo and visual-asset library for this chapter,
organized for the project. These are the source-of-truth files.

> **Not deployed.** This folder lives at the repo root, *outside* `public/`, so
> Cloudflare does **not** serve or upload it. The website uses a small selection
> of these (copied into `public/assets/`); everything else is kept here for
> design/print use and as a record.
>
> InterVarsity®, InterVarsity Christian Fellowship/USA®, and the InterVarsity
> logo are trademarks of InterVarsity Christian Fellowship/USA.

## Color variants (logos)

- **gradient** — the primary, full-color logo. Use on white/light backgrounds.
- **white** — reversed; use on dark/photo backgrounds.
- **grayscale** — single-tone gray, for limited/no-color contexts.
- **1-color / 2-color** (eps) — print-limited color situations.

## Recommended for this website

- **Header** (light): `logos/horizontal/InterVarsity_horizontal_gradient.png`
- **Footer** (navy): `logos/horizontal/InterVarsity_horizontal_white.png`
- **Favicon / avatar**: the mark cropped from a horizontal/vertical logo, or
  `logos/vertical-small/*`
- **Divot border**: `visual-assets/divots/divotborder_orange gradient_17 center.png`
  (or the vector `.eps`)
- **Concentric circles** (hero accents): `visual-assets/concentric-circles/*`

## Format notes

- **PNG** — transparent background; ready for web.
- **AI / EPS** — Adobe Illustrator / vector source, for print and design tools.
- A chapter lockup ("InterVarsity | Northern Michigan University") should still
  be produced via the official **chapter logo generator** for production use.
