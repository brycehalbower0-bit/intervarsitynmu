# Project guide for Claude

Website mock-up for **InterVarsity Christian Fellowship at Northern Michigan
University**, deployed as a **Cloudflare Workers + static assets** project.

## Architecture
- Static site lives in `public/` (`index.html`, `404.html`, plus `calendar.html`
  and `community.html` for the community platform).
- `src/index.js` is the Worker: serves assets via the `ASSETS` binding and
  handles `GET /api/health`, `POST /api/contact`, and `POST /api/subscribe`
  (the President's newsletter opt-in).
- The **community platform** lives under `/api/community/*` (`src/community.js`
  + `src/lib/*`): passwordless magic-link accounts, a public calendar, event
  discussion threads, and leader moderation (banned-word gate → review queue),
  backed by **Cloudflare D1** (schema/seed in `migrations/`). Front-end:
  `public/calendar.html` (public) and `public/community.html` (the app), with
  `public/scripts/{calendar,community}.js` and `public/styles/community.css`.
  Access is `@nmu.edu` self-serve plus leader-issued invites; `LEADER_EMAILS`
  seeds leaders. DMs are planned (Phase 3) and not yet built.
- `wrangler.jsonc` routes only `/api/*` through the Worker
  (`assets.run_worker_first`); everything else is served statically.
- No build step for the site. Only `og.png` is generated by
  `tools/build-og.py` (`npm run build:og`, needs Python + Pillow).
- Official brand art: web copies live in `public/assets/{logos,icons,brand}`;
  the full official pack is in `brand-assets/` at the repo root (NOT under
  `public/`, so it is not deployed).

## Commands
- `npm run dev` → `wrangler dev` (local)
- `npm run deploy` → `wrangler deploy`
- `npm run tail` → stream Worker logs (see contact submissions)
- `npm test` → community API integration test (Node `--experimental-sqlite`)
- `npm run db:migrate` / `npm run db:migrate:remote` → apply D1 migrations
  (local / production)

## Brand rules (InterVarsity Brand Book 2026)
- Primary colors lead: Revival Orange `#E76127`, Missional Blue `#006880`,
  Text Gray `#333333`. Secondary colors are accents only. All tokens are CSS
  variables at the top of `public/styles/main.css`.
- Gradients must be linear (light moving up/right).
- Fonts: Montserrat (display), Mulish (body), Zilla Slab (wordmark).
- The footer MUST keep "InterVarsity Christian Fellowship/USA" linking to
  intervarsity.org. The chapter logo must stay in the top of the page.

## Important
- The site uses the **official** InterVarsity logos and 2024 icon set (in
  `public/assets/`). For production, generate the chapter lockup
  ("InterVarsity | Northern Michigan University") from the official chapter
  logo generator and drop it in.
- Content (names, times, events, socials) is placeholder — see "Make it yours"
  in `README.md`.
